# 狗头军师 Jev Chat · Windows 源码适配

新增统一云服务模式：在设置顶部选择“统一云服务”，应用服务器地址，再用服务端预建的邮箱账号登录。正式地址为 `https://api.zovoeh.cn`；本机联调仍可使用开发隧道 `http://127.0.0.1:18000`。其他明文 HTTP 地址及跳转会被拒绝。此模式不需要填写模型 Key，识图使用本地 RapidOCR。

登录后可新建或编辑人物、查看三端共享的已确认聊天与分析结果、编辑通用笔记。采集会话需手动关联到选定人物；同名不会自动合并。核对原文后，先将人物与已确认文本同步，再创建服务端分析任务。详细解释和改写也经过网关；界面保留服务端候选顺序，缺失权重时不显示百分比。

0.2.1-preview 起，可直接在核对页顶部选已有联系人或新建，不必先去账号页关联。
“本轮想法”可填写当时状态、背景和回复目标，最多2000字；随本次分析和后续改写使用，
不自动写为长期记忆。没有可靠标题时必须选人，本轮独立建会话，避免占位标题串档。
取消核对不创建人物、会话或身份关联，已有历史不随重新关联移动。

结果页的“证据与原文出处”及资料页的历史分析选择器，可逐条查看事实、推测和未知结论的原文引用、说话人及时间。来源使用分析当时的原文快照，引用不可用时会明确说明；有引用不表示结论一定正确。可将所选结论保存为待确认记忆；没有引用时会先询问是否作为你的手动陈述保存。

云账号设置中的“长期记忆”支持手动新增、更正并填写原因、明确确认事实、退回待确认和确认后删除。新增、更正、恢复和推测转为事实后，都需先关闭此窗口并点“立即同步”，再打开记忆单独确认事实；未同步内容不能确认，避免两次操作在队列中合并。更正和恢复都会回到待确认。历史按页联网读取，恢复会基于当前版本产生新的待确认修改。离线编辑继续使用原待同步队列，版本冲突需在“处理冲突”中解决。账号变化、来源删除或历史返回404时，相关证据与历史窗口会清空；已经删除的记忆不能恢复。

云资料和待上传队列按账号保存为 `%LOCALAPPDATA%/GoutouJunshi/cloud/accounts/` 下的 SQLite；会话凭据由当前 Windows 用户的 DPAPI 加密，密码不落盘。前台每15秒检查同步，也可点“立即同步”；断网保留队列，重新打开后继续。冲突会同时保留本地与远端，需在“处理冲突”中选择。401 要求重新登录，不会切换到设备旧 Key。

“旧人物迁移预览”会列出旧 `config.json` 中的关系档案，仅确认后导入当前账号；保留旧文件和稳定来源映射，重复导入不会重复建人物。旧进程已丢失的内存聊天无法恢复。服务器恢复备份后，旧队列冻结并保存完整恢复副本；只有明确确认重新拉取才启用新快照，旧队列不自动回灌。资料页可继续查询已有分析任务；明确新建请求前会提示可能额外计费。

以下模型 Key、云端识图与本地保存描述针对旧直连模式，统一云服务以前文说明为准。

本目录基于 [jev-chat-windows](https://github.com/jev-chat/jev-chat-windows) 的窗口采集、RapidOCR、悬浮窗和草稿填入链路。接入狗头军师的证据边界与自然口吻约束：先核对识别原文及说话人，再做策略判断、生成并排序候选；悬浮窗显示可能意图、模型估计的判断把握、已知事实、仍未知、下一步和停止条件。对方明确要求停止联系时，这轮不生成候选。**目标聊天应用可在设置页切换：微信（默认）或 QQ（QQNT 主面板内嵌形态）。**

**状态：可构建预览 ZIP。贡献者 @wstaery 在 PR #2 中报告 QQNT 路径已在一台 Windows 10 实机完成识别与填入验证；微信各版本的实机验收仍待进行。** GitHub Actions 会提供预览包；构建通过不代表所有聊天应用版本实机测试通过。策略可选 Jev 或 DeepSeek 官方；DeepSeek 独立整理证据，尝试以三次标签轮换的首 token 权重核对策略，无法稳定取得权重时明确标注不可用。候选百分比为本轮相对推荐权重，并非回复成功率。

使用流程：打开目标应用（微信或 QQ）的会话并保持窗口可见（QQ **只保留单聊**：用主面板内嵌聊天，独立聊天窗口暂不支持，切到群聊会提示跳过、切回好友自动恢复；换了窗口就重新拨一次「采集」开关，会自动重新找窗口接过去）；首次进入设置，选择目标聊天应用、策略与回复模型，配置 Key；识图可选本地 RapidOCR、DeepSeek 图片识别或 OpenRouter 图片识别。点「采集」会立刻显示当前窗口的会话；**采集中直接上滑翻出更早的消息，停稳后会自动把新露出的记录并入累计**（也可重拨一次「采集」强制重读）；核对弹窗里可以点「累计聊天记录」，合并后再次核对并确认分析。记录按对话先后顺序保留最近 60 条；手动修改与删除会保留。请小幅连续滚动、保留部分重叠；没有重叠的扫描默认按更早的历史处理，时间顺序仍需人工核对。云端识图会上传裁剪后的聊天区截图并可能计费。读取新消息后点「核对原文并分析」，逐行修正“我／对方”的归属和文字，再确认。结果页可选「详细分析」「更像我一点」，也可复制或填入候选草稿。K 线窗口内置五种走势并支持导入带 `timestamp,sender,message` 的聊天 CSV；图中展示消息方向净差，无法衡量关系质量。设置页可按会话保存阶段、目标和简短背景；完整聊天仅留在运行时内存。OCR 可能认错说话人，填入前还须确认当前会话、收件人和文字；程序不会自动发送。

要求 Windows 10 1903+ 或 Windows 11、微信 Windows 4.x 或 QQNT（QQ 9.x）、Python 3.10–3.12。源码运行：

```powershell
cd integrations\jev_windows
py -3.11 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
```

QQ 适配说明：按 QQNT 主面板标定（浅色皮肤、100% 显示缩放、默认列表宽度）；**只保留单聊**（切到群聊会提示跳过、切回好友自动恢复）；深色主题尽力兼容，独立聊天窗口与明显不合常规的窗口布局尚未覆盖。切换目标应用后采集会自动重启；QQ 或微信没打开时先打开主窗口再开启采集。

密钥写入当前 Windows 用户的 `GOUTOU_JEV_API_KEY`、`GOUTOU_DEEPSEEK_STRATEGY_KEY`、`GOUTOU_LLM_API_KEY` 和 `GOUTOU_OCR_API_KEY` 环境变量（按实际选择填写）；识图来源与回复来源相同时可以复用回复 Key。不会读取原版 Jev 安装时保存的 Key。其他设置写在本目录的 `config.json`，已被 Git 忽略。`build.bat` 可在 Windows 上生成可执行目录和 `dist/goutoujunshi-jev-chat-windows-preview.zip`；ZIP 解压后保持整个目录完整，从其中运行 `.exe`。数据使用见仓库根目录 [说明](../../PRIVACY.md)。

本轮整合补充云端识图去重接口、QQ 群聊分析与填入拦截、记录时间顺序、微信／QQ 同名会话隔离和累计后确认的回归修复。关系资料按应用分别保存，原有微信资料继续兼容。源码合并不会自动替换 Release ZIP；QQ 支持请使用本轮 Actions 成功构建的 Windows Artifacts 或运行源码。
